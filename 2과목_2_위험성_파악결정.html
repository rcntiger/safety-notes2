세부항목 1 · 위험성 평가

1위험성평가의 정의·개요 · 대상 · 항목 · 관련 법

산업안전보건법 제36조 · 시행규칙 제37조 · 고시「사업장 위험성평가에 관한 지침」

① 정의

사업주가 스스로 유해·위험요인을 파악하고 그 위험성 수준을 결정하여, 위험성을 낮추기 위한 적절한 조치를 마련하고 실행하는 과정

② 절차

"준비하고, 찾고, 정하고, 줄이고, 적는다"
① 사전준비 → ② 유해·위험요인 파악 → ③ 위험성 결정 → ④ 위험성 감소대책 수립·실행 → ⑤ 실시내용·결과 기록·보존
  • 사전준비: 실시규정 작성, 평가대상 확정, 안전보건정보(작업표준, MSDS, 재해사례 등) 조사
  • 유해·위험요인 파악 방법: 사업장 순회점검(필수), 근로자 청취조사, 안전보건 자료, 체크리스트 등

③ 실시 주체 · 시기

  • 사업주가 근로자를 참여시켜 실시 (유해·위험요인 파악, 감소대책 수립·이행 확인 등에 참여)
종류시기
최초평가사업 성립일(건설업은 실착공일)부터 1개월 이내 착수
수시평가기계·기구 신규 도입·변경, 공정 변경, 중대재해 발생 등 바뀔 때
정기평가최초평가 후 매년 재검토
상시평가월 1회 이상 위험요인 발굴 + 주 1회 이상 공유(TBM 등) → 수시·정기평가를 한 것으로 봄
"최초 한 달, 수시는 바뀔 때, 정기 매년, 상시는 매달·매주"

④ 평가대상 · 방법 · 기록

  • 대상: 근로자에게 노출되었거나 노출될 것이 합리적으로 예견되는 모든 유해·위험요인 (매우 경미한 것은 제외 가능)
  • 방법: 위험 가능성·중대성 조합(빈도·강도법), 체크리스트법, 위험성 수준 3단계 판단법, 핵심요인 기술법(OPS) 등 — 사업장 규모·특성에 맞게 선택
  • 결과 기록·보존: 3년 / 근로자에게 결과 공유(게시·교육·TBM)
"위험성평가 기록은 3년" — 서류 보존 원칙(3년)과 같다
파악→결정→감소→기록! 최초 한 달·정기 매년·수시 바뀔 때! 근로자 참여, 기록 3년!
세부항목 2 · 시스템 위험성 추정 및 결정

2-1시스템 위험성 분석 및 관리

① 시스템 안전

  • 시스템 수명주기 전 단계에서 위험을 확인·평가·제어해 사고를 최소화하는 것
수명주기 5단계: "구정개생운" → 구정(舊正)에 개가 생운(生運)을 얻다
구상(개념) → 정의 → 개발 → 생산 → 운용(배치·폐기)

② 위험의 심각도 (MIL-STD-882)

범주등급내용
I파국적 (catastrophic)사망, 시스템 손실
II위기적 (critical)중상해, 큰 손상 — 즉시 조치 필요
III한계적 (marginal)경상해, 경미한 손상 — 제어 가능
IV무시 가능 (negligible)상해·손상 없음
"파위한무" → 파도가 위로 한계까지 무섭게 친다 (I 파국 → IV 무시)
  • 발생 빈도: A 자주(frequent) → B 보통(probable) → C 가끔(occasional) → D 거의 없음(remote) → E 극히 희박(improbable)
구정개생운! 파국·위기·한계·무시!

2-2위험분석 기법

기법내용성격
PHA (예비위험분석)시스템 개발 최초 단계(구상)에서 위험 상태를 개략적으로 분석정성
FHA (결함위험분석)서브시스템 간 인터페이스·결함 분석 (여러 회사가 분담 제작할 때)정성
FMEA (고장형태와 영향분석)부품의 고장 형태별로 상위 시스템에 미치는 영향을 표로 분석귀납·정성
CA (치명도 분석)고장의 치명도를 정량화 (FMEA + CA = FMECA)정량
ETA (사건수 분석)초기 사건에서 시작해 성공/실패로 나뭇가지처럼 결과 전개귀납·정량
FTA (결함수 분석)정상사상(사고)에서 원인을 거꾸로 찾아 내려감연역·정량
HAZOP가이드워드로 공정 변수의 이탈을 찾음 (화학공정)정성
MORTFTA 같은 논리로 관리·설계·생산·보전까지 광범위 분석 (원자력)연역
O&SHA운용·지원 단계의 위험 분석—
THERP인간 실수율 예측정량
"FTA만 위에서 아래로(연역), FMEA·ETA는 아래에서 위로(귀납)"
PHA는 '맨 처음(Preliminary)', FMEA는 '부품 고장', HAZOP은 '공정 이탈', MORT는 '관리까지'

HAZOP 가이드워드

가이드워드뜻
No / Not설계 의도의 완전한 부정
More / Less양의 증가 / 감소
As well as성질상의 증가 (다른 것이 더 있음)
Part of성질상의 감소 (일부만)
Reverse설계 의도의 논리적 반대
Other than완전한 대체
'As well as' = 성질상 증가, 'Part of' = 성질상 감소, 'More/Less' = 양의 증감

FMEA 영향 확률(β)

  • 실제 손실 β = 1.0 · 예상되는 손실 0.1 ≤ β < 1.0 · 가능한 손실 0 < β < 0.1 · 영향 없음 β = 0
PHA는 처음, FMEA는 부품, ETA는 가지, FTA만 연역, HAZOP은 가이드워드!

2-3결함수 분석 (FTA)

① 특징

  • 1962년 벨 연구소 왓슨(Watson)이 개발
  • 연역적(Top-down) · 정량적 · 논리기호로 사고 원인을 나무 형태로 표현
  • 절차: 정상사상 선정 → FT도 작성 → 컷셋·최소 컷셋 산출 → 확률 계산(정량 평가) → 개선

② 논리기호

기호모양뜻
결함사상직사각형더 분석할 사상 (정상사상·중간사상)
기본사상원더 이상 분해하지 않는 기본 원인
생략사상마름모정보 부족·분석 불충분으로 더 전개하지 않음
통상사상집 모양정상적으로 일어날 것이 예상되는 사상
전이기호삼각형다른 곳으로 이어짐(in/out)
AND 게이트반원(평평한 밑)입력이 모두 일어나야 출력
OR 게이트뾰족한 밑입력 중 하나라도 일어나면 출력
억제 게이트육각형조건을 만족할 때만 출력
우선적 AND—입력이 정해진 순서대로 일어나야 출력
조합 AND—n개 입력 중 m개 이상이 일어나면 출력
배타적 OR—입력 중 하나만 일어날 때 출력 (동시엔 X)
"네모는 더 파고, 동그라미는 끝, 마름모는 생략, 집은 늘 있는 일"

③ 컷셋 · 패스셋

  • 컷셋: 모두 일어나면 정상사상(사고)이 일어나는 기본사상의 집합 → 최소 컷셋 = 시스템의 위험성
  • 패스셋: 모두 일어나지 않으면 정상사상이 일어나지 않는 집합 → 최소 패스셋 = 시스템의 신뢰성
"컷셋은 사고 나는 길, 패스셋은 피해 가는 길"

④ 확률 계산

  • AND: T = q₁ × q₂ × … (곱)
  • OR: T = 1 − (1 − q₁)(1 − q₂)…
  • 불 대수: A·A = A, A + A = A, A + A·B = A (흡수법칙) → 최소 컷셋 구할 때 사용
예: q₁ = 0.1, q₂ = 0.2 → AND 0.02, OR 1 − 0.9 × 0.8 = 0.28
FTA는 왓슨·연역·정량! AND는 곱, OR는 1 − 곱! 컷셋은 사고 길, 패스셋은 피하는 길!

2-4정성적·정량적 분석 · 신뢰도 계산

① 정성적 vs 정량적

  • 정성적: 위험의 종류·원인을 말로 파악 (PHA, FMEA, HAZOP, 체크리스트, What-if)
  • 정량적: 확률·수치로 계산 (FTA, ETA, CA, THERP)

② 신뢰도 기본식

용어식
고장률 λ고장 건수 ÷ 총 가동시간
신뢰도 R(t)e−λt (지수분포, 우발고장기간)
MTBF1 ÷ λ (수리 가능한 제품의 평균 고장 간격)
MTTF수리 불가능한 제품의 평균 고장 시간
가용도 AMTBF ÷ (MTBF + MTTR)
"MTBF는 Between(사이) — 고치며 쓰는 것, MTTF는 To(까지) — 한 번 쓰고 버리는 것"

③ 직렬 · 병렬 신뢰도

  • 직렬: R = R₁ × R₂ × … (하나만 고장 나도 전체 고장)
  • 병렬: R = 1 − (1 − R₁)(1 − R₂)… (모두 고장 나야 전체 고장)
  • 동일 부품 n개 — 직렬 MTTF = MTTF ÷ n / 병렬 MTTF = MTTF × (1 + 1/2 + … + 1/n)
예: 0.9 두 개 → 직렬 0.81, 병렬 0.99
"직렬은 곱해서 작아지고, 병렬은 실패끼리 곱해 1에서 뺀다"

④ 고장률 곡선 (욕조곡선)

기간고장률원인·대책
초기 고장감소형설계·제조 결함 → 디버깅, 번인(burn-in)
우발 고장일정형예측 불가, 우발적 → 지수분포, 극한 상황 회피
마모 고장증가형노화·마모 → 예방보전, 교체
"초감 · 우일 · 마증" → 초반엔 줄고, 중간엔 일정하고, 마지막엔 는다
R = e^−λt, MTBF = 1/λ! 직렬은 곱, 병렬은 1 − 실패곱! 초감·우일·마증!

세부항목 1 · 인간공학의 정의

1인간공학의 정의 · 목적 · 필요성 · 적용분야

① 정의

  • 인간의 특성·능력·한계를 고려해 기계·작업·환경을 설계하는 학문 → "일을 사람에게 맞춘다" (Fitting the job to the man)
  • 차파니스(Chapanis): 기계와 그 조작·환경조건을 인간의 특성·능력·한계에 잘 조화하도록 설계하기 위한 수법
  • 다른 이름: Ergonomics, Human Factors (Engineering)
"사람을 일에 맞춘다(선발·훈련)"는 인간공학의 기본 개념이 아님

② 목적 (차파니스)

"안·능·쾌" → 안전해야 능률이 오르고 쾌적하다
안전성 향상과 사고 방지 · 기계 조작의 능률성과 생산성 향상 · 쾌적성(편리성) 향상

③ 배경 · 필요성 · 작업관리

  • 배경: 2차 세계대전 무렵 복잡한 무기 조작 실수 → 기계 중심에서 인간 중심 설계로 전환
  • 필요성: 산업재해·근골격계질환 감소, 생산성·품질 향상, 노사 신뢰, 법적 요구(근골격계 예방 의무)
  • 작업관리와 인간공학: 작업관리(방법연구 + 작업측정)에 인간공학을 적용해 안전하고 효율적인 작업방법을 만든다

④ 사업장 적용분야

  • 작업관련 유해·위험 작업 분석, 작업장·공구·설비 설계, 인간-기계 인터페이스(표시·조종장치), 작업환경(조명·소음·온열) 개선, 근골격계질환 예방, 제품 설계

⑤ 인간공학 연구 기준(척도)의 요건

"적무신민" → 적(敵)이 없는(무) 신민(臣民)
적절성(타당성: 의도한 목적에 맞는가) · 무오염성(측정하려는 변수 외 영향 없음) · 기준척도의 신뢰성(반복성) · 민감도(차이를 잘 구별)
일을 사람에게 맞춘다! 목적은 안·능·쾌, 연구 기준은 적무신민!
세부항목 2 · 인간-기계체계

2인간-기계 시스템의 정의·유형 · 시스템의 특성

① 인간-기계 시스템의 기본 기능

"감저처행" → 감자를 저장했다가 처리해서 행동한다
감지(정보 수용) → 정보 저장 → 정보 처리 및 의사결정 → 행동 기능
  • 정보 저장은 다른 세 기능 모두와 연결된다 (기억은 모든 단계에서 쓰임)

② 시스템의 유형

유형동력제어예
수동 시스템인간인간수공구
기계화(반자동) 시스템기계인간자동차 운전, 공작기계 조작
자동화 시스템기계기계 (인간은 감시·정비)자동화 공정, 로봇
"손(수동) → 기계 힘 + 사람 운전(기계화) → 기계가 다 하고 사람은 지켜봄(자동화)"

③ 인간과 기계의 장점 비교

인간이 우수기계가 우수
낮은 수준의 자극 감지
예기치 못한 사건 감지
귀납적 추리
융통성·임기응변
다양한 경험으로 문제 해결
주관적 평가·판단		반복 작업을 신뢰성 있게
연역적 추리
정보의 신속·정확한 저장·회수
큰 힘, 과부하에서도 효율 유지
장시간 일관된 작업
인간 감지 범위 밖 자극(X선·초음파) 감지
"인간은 귀납·융통·예상 밖, 기계는 연역·반복·저장·힘"
귀납적 추리 = 인간, 연역적 추리 = 기계. 바꿔 낸 보기 단골

④ 시스템의 특성

  • 목적 지향성 · 요소(인간·기계·환경)의 집합 · 요소 간 상호작용 · 입력 → 처리 → 출력 · 환경과의 경계 · 피드백(제어)
감저처행! 수동·기계화·자동화, 인간은 귀납, 기계는 연역!
세부항목 3 · 체계설계와 인간요소

3체계설계 6단계 · 감성공학

① 체계설계 과정 6단계

"목정기계촉시" → 목정(나무 요정)이 기계를 재촉(촉)해 시험한다
① 목표 및 성능명세 결정 → ② 체계의 정의 → ③ 기본설계 → ④ 계면설계 → ⑤ 촉진물 설계 → ⑥ 시험 및 평가
단계주요 내용
기본설계기능 할당(인간 vs 기계), 인간 성능 요건 명세, 직무분석, 작업설계
계면설계인간-기계 접점 설계: 작업공간, 표시장치, 조종장치, 컴퓨터 대화
촉진물 설계인간 성능을 돕는 보조물: 지시수첩(매뉴얼), 성능 보조자료, 훈련 도구·계획
시험 및 평가체계가 목표대로 작동하는지, 인간 성능이 적합한지 확인
'기능 할당'은 기본설계, '매뉴얼·훈련'은 촉진물 설계

② 안전설계 기법

기법뜻예
Fail-safe기계가 고장 나도 안전한 쪽으로 작동정전 시 엘리베이터 정지
Fool-proof사람이 실수해도 사고가 나지 않게인터록, 가드, 양수조작식
Tamper-proof사람이 고의로 안전장치를 무효화하지 못하게방호장치 해체 시 기계 정지
"Fail은 기계 고장, Fool은 사람 실수, Tamper는 사람의 고의"
Fail-safe 3단계: fail-passive(고장 시 정지) → fail-active(경보 후 짧은 시간 운전) → fail-operational(고장 나도 다음 보수까지 운전)

③ 감성공학

  • 인간의 감성(느낌·이미지)을 정량화해 물리적 설계 요소로 바꾸는 기술
  • 1류: 감성 어휘(SD법)로 디자인 요소 연결 / 2류: 연령·성별·생활양식 고려 / 3류: 수학적 모델(퍼지·신경망)로 컴퓨터 지원
"1류 말(어휘), 2류 삶(생활양식), 3류 셈(수학 모델)"
목정기계촉시! 기능할당은 기본, 매뉴얼은 촉진물! Fail 고장·Fool 실수·Tamper 고의!
세부항목 4 · 인간요소와 휴먼에러

4-1인간실수의 분류 · 형태적 특성

① 스웨인(Swain)의 분류 — 행위(독립행동) 관점

오류뜻
생략 오류 (omission)필요한 작업·절차를 하지 않음
실행 오류 (commission)작업을 잘못 수행
순서 오류 (sequential)순서를 잘못 수행
시간 오류 (time)너무 빠르거나 늦게 수행
불필요한 행동 오류 (extraneous)하지 않아도 될 일을 함
"빼먹고(생략), 틀리고(실행), 순서 바꾸고, 늦고(시간), 쓸데없는 짓(불필요)"
밸브를 잠그는 것을 '잊음' = 생략 오류 / 다른 밸브를 잠금 = 실행 오류

② 원인 수준에 따른 분류

  • Primary error: 작업자 자신으로부터 직접 발생
  • Secondary error: 작업 조건(형태·환경)의 문제로 발생
  • Command error: 필요한 물건·정보·에너지가 공급되지 않아 작업자가 움직이려 해도 움직일 수 없는 상태

③ 리즌(Reason)의 불안전 행동 분류

구분유형뜻
비의도적실수 (slip)의도는 맞는데 실행이 잘못됨
건망증 (lapse)기억 실패로 빠뜨림
의도적착오 (mistake)상황 해석·의도(목표) 자체가 잘못됨
위반 (violation)알면서 규칙을 어김
"slip은 미끄러진 손, lapse는 깜빡, mistake는 잘못된 머리, violation은 고의"
라스무센 행동 수준: 숙련 기반(skill) · 규칙 기반(rule) · 지식 기반(knowledge) → slip은 숙련, mistake는 규칙·지식 기반에서
'상황을 잘못 해석해 틀린 목표를 세움' = 착오(mistake), '의도와 다르게 행동' = 실수(slip)

④ 정보처리 과정에 따른 분류

  • 인지·확인 오류 → 판단·기억 오류 → 동작·조작 오류 (1과목 착오의 '인판조'와 연결)
빼먹고·틀리고·순서·늦고·쓸데없는 짓! slip은 손, mistake는 머리!

4-2인간실수 확률 추정기법 · 예방기법

① 인간실수 확률 (HEP)

  • HEP = 실제 인간 에러 수 ÷ 에러가 발생할 수 있는 전체 기회 수
  • 인간 신뢰도 R = 1 − HEP
  • 여러 작업 연속(직렬): R = R₁ × R₂ × … / 2인 상호 확인(병렬): R = 1 − (1 − R₁)(1 − R₂)
예: 1,000번 중 5번 실수 → HEP 0.005, 신뢰도 0.995

② 추정기법

기법내용
THERP인간 실수율 예측 기법 — 사건나무(확률 나무)로 정량 분석 (대표 기법)
CIT (위급사건기법)사고·준사고 경험을 면접으로 수집해 위험요인 파악
OAT (조작자 행동나무)조작자의 감지·진단·반응을 나무 형태로 분석
HCR인지 신뢰도 — 시간에 따른 반응 실패 확률
인간실수 자료은행과거 실수 자료를 축적해 확률 추정
"THERP는 사람(Human) 실수 확률(Rate) 예측(Prediction)" — 이름 자체가 정의

③ 예방기법

  • 설계: 배타설계(에러 원천 제거) → 보호설계(에러 가능성 최소화) → 안전설계(에러가 나도 피해 최소: fail-safe) / fool-proof, 인터록
  • 작업자: 적성 배치, 교육·훈련, 동기부여
  • 관리: 작업 표준화, 작업절차서, 2인 확인(병렬화), 작업환경 개선
"배·보·안" → 배제가 최선, 그다음 보호, 마지막 안전(피해 최소)
HEP = 실수 ÷ 기회, R = 1 − HEP! THERP는 사건나무! 배·보·안!

1-1안전과 위험의 개념

① 용어 구분

용어뜻
위험 (Hazard)사고를 일으킬 수 있는 잠재적 원인 = 유해·위험요인
위험성 (Risk)위험요인이 사고로 이어질 가능성(빈도) × 중대성(강도)
사고 (Accident)원하지 않고 비효율적인, 변형된 사건
재해 (Loss)사고의 결과로 생긴 인적·물적 손실
아차사고 (Near Miss)인적·물적 손실이 없는 사고
산업재해노무를 제공하는 사람이 업무 관련 설비·물질이나 작업 때문에 사망·부상·질병에 걸리는 것
중대재해사망 1명 이상 · 3개월 이상 요양 부상자 동시 2명 이상 · 부상자·직업성 질병자 동시 10명 이상
"해저드는 씨앗, 리스크는 싹 틀 확률 × 얼마나 클지"
Hazard(원인 자체) ≠ Risk(가능성 × 중대성). 위험성 = 가·중 → "가중(加重)되는 위험성" / 중대재해는 "1·2·10"
"위험성 = 빈도 + 강도"처럼 더하기로 낸 보기 주의. 곱(조합)입니다.

② 사고의 본질적 특성

"시간 · 우법 · 필우 · 재불" → 시간 맞춰 온 우(友)법, 필우(筆友)는 재불(再不)
사고의 시간성 · 우연성 중의 법칙성 · 필연성 중의 우연성 · 사고의 재현 불가능성
"재현 가능성"은 오답. 똑같은 사고는 다시 만들 수 없음

③ 재해 발생 형태

  • 단순자극형(집중형): 요인이 한곳에 집중되어 순간적으로 발생
  • 연쇄형: 하나의 요인이 다른 요인을 낳으며 사슬처럼 이어짐
  • 복합형: 집중형 + 연쇄형
"한 번에 쾅(집중), 줄줄이(연쇄), 둘 다(복합)"
해저드는 씨앗, 리스크는 가중! 시간 우법 필우 재불!

1-2안전보건관리 제이론

① 하인리히 도미노 이론 (5단계)

"사개불사재" → 사(四)개 도미노 사이에 불(火)이 붙어 사재(私財)를 태운다
① 사회적 환경·유전적 요소 → ② 개인적 결함 → ③ 불안전한 행동·상태 → ④ 사고 → ⑤ 재해(상해)
  • 핵심: 3단계(불안전한 행동·상태)를 빼면 도미노가 멈춘다 → 사고 예방
  • 직접원인 비율: 불안전한 행동 88% · 불안전한 상태 10% · 불가항력 2%
"가운데 불만 끄면 산다" / "팔팔(88)한 사람이 사고 친다"

② 버드 신도미노 이론

"통기직사상" → 통기(通氣)창으로 들어온 직사광선에 상처 입다
① 통제의 부족(관리) → ② 기본원인(기원) → ③ 직접원인(징후) → ④ 사고(접촉) → ⑤ 상해(손실)
괄호 속 단어: "관기징접손" → 관기(官妓)가 징을 접고 손을 씻다
관리 · 기원 · 징후 · 접촉 · 손실
  • 근원은 관리(통제) 부족, 예방은 기본원인(4M) 제거 — 기본원인 = 개인적 요인 + 작업상 요인
하인리히는 "3단계 제거", 버드는 "기본원인 제거·관리 부족이 근원"

③ 아담스 · 웨버 이론

이론5단계암기
아담스관리구조 → 작전적 에러 → 전술적 에러 → 사고 → 상해"관(官)이 작전·전술 짜다 사상자"
웨버유전·환경 → 인간의 실수 → 불안전 행동·상태 → 사고 → 상해"유실물(유·실·불) 사고"
아담스: "작전은 윗선(경영자·감독자), 전술은 현장(불안전 행동·상태)"

④ 재해 구성 비율

이론비율의미
하인리히1 : 29 : 300 (합 330)중상해 : 경상해 : 무상해 사고
버드1 : 10 : 30 : 600 (합 641)중상·폐질 : 경상 : 무상해 사고(물적손실) : 무상해·무사고(아차사고)
"하인(下人)은 이구(29) 삼백(300), 버드(새)는 일·십·삼십·육백 짹짹"
비율 문제는 배수로 계산 (하인리히 경상 58건 → 무상해 600건)

⑤ 재해예방 4원칙

"손원예대" → 손님은 원래 예약 대기
손실우연 · 원인계기(연계) · 예방가능 · 대책선정의 원칙
  • 손실우연: 사고 결과 손실의 크기는 우연
  • 원인계기: 사고에는 반드시 원인이 있고, 원인은 필연·복합적
  • 예방가능: 천재지변을 뺀 인재는 모두 예방 가능 / 대책선정: 원인에 맞는 대책(3E)이 반드시 있다
"손실은 우연, 원인은 필연" — 둘을 바꾼 보기 주의

⑥ 사고예방대책 기본원리 5단계

"조·사·분·선·적" → 조사관이 분석해서 선택하고 적용한다
① 안전조직 → ② 사실의 발견 → ③ 분석·평가 → ④ 시정방법의 선정 → ⑤ 시정책의 적용(3E)
3E: "기교관(技巧官)" → 기술 · 교육 · 관리
Engineering · Education · Enforcement → 4E는 + Environment
Economy(경제)는 3E가 아님
사개불사재·통기직사상! 하인 이구삼백, 버드 일십삼십육백! 손원예대, 조사분선적, 기교관!

1-3생산성과 경제적 안전도

① 재해손실비 산정 방식

학자방식암기
하인리히직접비 : 간접비 = 1 : 4 → 총비용 = 직접비 × 5"하인은 일사(1:4)분란"
시몬즈총비용 = 보험 코스트 + 비보험 코스트"시몬즈는 보험 둘"
버드보험비 1 : 비보험 재산비용 5~50 : 비보험 기타 1~3"버드는 빙산"
콤페스총비용 = 공동비용 + 개별비용"콤퍼스로 원 두 개"

② 시몬즈 비보험 코스트

A×휴업상해 + B×통원상해 + C×응급조치 + D×무상해사고 (건수)

"휴통응무" → 휴(休)일에 통(痛)증 오면 응급실, 무(無)사하길
사망·영구 전노동불능 상해는 비보험 코스트 산정 항목에서 제외

③ 직접비 vs 간접비

  • 직접비 = 산재보험 급여: 요양·휴업·장해·간병·유족급여, 상병보상연금, 장의비, 직업재활급여
  • 간접비: 인적손실(시간), 물적손실(설비), 생산손실(중단), 특수손실 등
"직접비는 보험에서 나가는 돈, 간접비는 공장이 멈춰서 잃는 돈"
직접비 8종: "요휴장간 유상장직" → 요가 강사가 휴강하자 장간(장기간) 유상으로 장직을 맡다
생산중단·설비손실은 간접비. 직접비 1억 → 하인리히 총비용 5억

④ 안전과 생산성

  • 안전관리 효과: 재해 감소 → 생산성·품질 향상, 근로자 사기 향상, 손실비 감소, 기업 신뢰도 상승
"안전관리는 원가를 높여 생산성을 떨어뜨린다"는 오답
하인 일사, 시몬즈 보험 둘(휴통응무), 버드 빙산, 콤페스 원 두 개!

1-4재해예방활동기법

① 무재해운동

3원칙: "무참선" → 무(無)념무상으로 참선(參禪)한다
무의 원칙(모든 위험요인 제거) · 참가의 원칙(전원 참가) · 선취의 원칙(안전제일, 미리 발견·해결)
3기둥: "최관소" → 위에서 아래로 최고 · 관리 · 소집단
최고경영자의 엄격한 경영자세 · 관리감독자에 의한 안전보건 추진(라인화) · 직장 소집단 자주활동 활성화

② 위험예지훈련 4라운드

"현본대목" → 현재 본대(本隊)의 대목표
1R 현상파악(어떤 위험?) → 2R 본질추구(이것이 위험 포인트) → 3R 대책수립(당신이라면?) → 4R 목표설정(우리는 이렇게 하자)

③ 브레인스토밍 4원칙

"비자대수" → 비자(visa) 받으러 대수(多數)가 몰렸다
비판금지 · 자유분방 · 대량발언 · 수정발언(편승)

④ TBM (Tool Box Meeting)

  • 작업 전 현장에서 짧게(5~15분) 소수 인원이 하는 위험예지 미팅
5단계: "도점작위확" → 도장(도점) 찍고 작위(爵位) 확인
도입 → 점검정비 → 작업지시 → 위험예지 → 확인

⑤ 안전점검 종류

"정수특임" → 정수기 특임(특별임무) 점검
정기점검(계획) · 수시점검(일상, 작업 전·중·후) · 특별점검(기계 신설·변경, 천재지변 후) · 임시점검(이상 발견 시)
무참선 하며 최관소 기둥 세우고, 현본대목·비자대수·도점작위확·정수특임!

1-5안전보건예산 편성 및 계상

① 사업장 안전보건예산

  • 대표이사 안전보건계획(500명 이상)에 안전보건 예산과 시설 현황을 포함 → 이사회 보고·승인 ("방·조·예·실")
  • 안전보건관리책임자가 예산을 확보·집행하도록 관리

② 건설업 산업안전보건관리비

  • 적용: 총공사금액 2천만 원 이상 건설공사
  • 계상: 발주자가 공사금액에 계상 → 수급인(시공자)이 사용
  • 산정: 대상액(재료비 + 직접노무비) × 공사 종류·규모별 요율
  • 목적 외 사용 금지, 사용내역 기록·보존
"이천만 원부터, 발주자가 쌓고 시공자가 쓴다"
대상액 = "재직(재료비 + 직접노무비)" → "재직 중인 사람 몫으로 계산"

③ 산업안전보건관리비 사용 항목

"사람·시설·보호구, 진단·교육·건강, 기술지도·본사·위험성평가"
안전관리자 등 인건비 · 안전시설비 · 보호구 · 안전보건진단비 · 안전보건교육비 · 근로자 건강장해예방비 · 기술지도비 · 본사 전담조직 인건비 · 위험성평가 등에 따른 비용
일반 공사용 장비, 공사 진행 자체에 필요한 비용(예: 일반 가설울타리·경비원 인건비)은 사용 불가
이천만 원부터 발주자가 쌓고 시공자가 쓴다! 대상액은 재직(재료비+직접노무비)!

② 관리자별 역할

"사장은 총괄, 반장은 현장, 참모는 조언"
안전보건관리책임자 = 총괄 / 관리감독자 = 현장(라인) / 안전·보건관리자 = 보좌·지도·조언(스탭)

③ 안전보건관리책임자 (총괄)

"계규교환 건원통 보위" → 계(契)모임 규칙으로 교환권 받고, 건물 원통하게 보위 섰다
예방계획 · 관리규정 작성·변경 · 안전보건교육 · 작업환경측정·개선 · 건강진단 · 재해 원인조사·재발방지 · 재해 통계 · 안전장치·보호구 적격품 확인 · 위험성평가

④ 관리감독자 (현장)

"점보 재정협위" → 점보(Jumbo) 비행기 재정을 협의한다
기계·설비 점검 · 작업복·보호구·방호장치 점검과 착용 지도 · 산업재해 보고·응급조치 · 정리정돈·통로 확보 · 안전·보건관리자 지도에 협조 · 위험성평가 참여

⑤ 안전관리자 (보좌·지도·조언)

"위위 적교 순원 통법 기록" → 위위~ 적의 다리를 순찰원이 통과법대로 기록

⑥ 보건관리자

MSDS 게시·비치 · 산업보건의 직무 보좌 · 의료행위 · 전체환기·국소배기장치 점검
의료행위(의사·간호사인 경우): "가볍게 응급, 악화 막고 요양, 약"
가벼운 부상 치료 · 응급처치 · 악화 방지 · 질병자 요양 지도 · 의약품 투여

소라·중스·대라스! 사장은 계규교환, 반장은 점보재정, 참모는 위위적교, 보건은 엠의의환!

2-2산업안전보건위원회 운영

산업안전보건법 제24조 · 시행령 제34조~제39조

① 설치 대상

  • 원칙: 상시근로자 100명 이상 (일부 위험 제조업 등은 50명 이상)
  • 건설업: 공사금액 120억 원 이상 (토목공사업 150억 원 이상)
"백 명이면 위원회, 건설은 백이십억(토목 백오십억)"
안전보건관리규정의 100명과 같은 숫자 → "규정도 백, 위원회도 백"

② 구성 (노사 동수)

근로자위원사용자위원
근로자대표
명예산업안전감독관
근로자대표가 지명한 9명 이내 근로자		사업 대표자
안전관리자 1명 · 보건관리자 1명
산업보건의
대표자가 지명한 9명 이내 부서장
"양쪽 다 대표 + 9명, 근로자 쪽엔 명예감독관, 사용자 쪽엔 안전·보건·의사"
안전관리자·보건관리자·산업보건의 = 사용자위원 / 명예산업안전감독관 = 근로자위원

③ 운영

  • 정기회의 분기마다 위원장이 소집 / 임시회의는 필요할 때
  • 의결: 재적위원 과반수 출석 + 출석위원 과반수 찬성
  • 위원장: 위원 중에서 호선 (노사 각 1명 공동위원장 가능)
  • 회의록 작성 · 2년 보존
"분기마다 모여 과반·과반, 호선으로 뽑고 2년 보관"

④ 심의·의결 사항

"계규교환 건원통 + 기계" (책임자 업무와 거의 같음)
예방계획 · 관리규정 · 안전보건교육 · 작업환경 · 건강관리 · 중대재해 원인조사·재발방지 · 재해통계 · 유해위험 기계 도입 시 안전조치
임금·복리후생은 심의·의결 사항이 아님
백 명이면 위원회, 양쪽 대표+9명, 분기마다 과반·과반, 2년 보관!

2-3안전보건경영시스템

① KOSHA-MS · ISO 45001

  • KOSHA-MS: 안전보건공단이 인증하는 국내 안전보건경영시스템
  • ISO 45001: 국제표준(2018), 기존 OHSAS 18001을 대체
  • 둘 다 PDCA 사이클이 기반
"KOSHA는 공단표, ISO는 세계표, 둘 다 PDCA로 돈다"
ISO 45001 구성 "상리계지 운성개" → 상리(上里) 계곡지에 운석이 개 위로 떨어지다
조직상황 · 리더십과 근로자 참여 · 계획 · 지원 · 운영 · 성과평가 · 개선

② PDCA 사이클 (데밍 사이클)

"Please Do Check Again" / 구조 "목방 교실 검 조표"
단계내용ISO 45001
P 계획목표 설정, 방법 결정상황·리더십·계획
D 실시교육훈련, 실시지원·운영
C 검토결과를 목표와 비교 검토성과평가
A 조치개선조치, 표준화개선
C와 A 순서 바꾼 보기 단골 / 반복할수록 수준이 오르는 나선형 상승

③ 안전보건관리계획

수립 유의사항: "독경(讀經)하던 실직자가 점점 근사해진다"
독자적(사업장 실태) · 경영층 방침 명확 · 실현 가능 · 직장 단위 구체적 · 점진적으로 높은 목표 · 근원적 해결
기본 방향: "유달산을 오른다" → 유지 → 달성 → 선취
평가척도: "절에서 상 받은 평범한 도사"
절대척도: 재해 건수 · 상대척도: 도수율·강도율 · 평정척도: 우수/보통/불량 · 도수척도: 중앙값·%
도수율은 상대척도! 도수척도(중앙값·%)와 구분

④ 대표이사 안전보건계획 (법 제14조)

  • 대상: 상시근로자 500명 이상 회사 / 시공능력 상위 1,000위 건설회사
  • 매년 이사회 보고·승인
"오백 명 회사 대표는 방에서 조용히 예습실"
경영방침 · 조직 구성·인원·역할 · 예산·시설 현황 · 전년도 실적·다음 연도 계획
KOSHA 공단표, ISO 세계표, Please Do Check Again! 독경 실직자가 유달산에서 절상평도!

2-4안전보건관리규정

산업안전보건법 제25조~제28조 · 시행규칙 별표2·3

① 작성 대상 · 기한

  • 원칙: 상시근로자 100명 이상 / 사무실형 업종은 300명 이상
  • 기한: 작성(변경) 사유 발생일부터 30일 이내
"기본 100, 앉아서 일하면 300 / 백 명이면 한 달"
300명 업종 → "농어민이 IT로 돈 벌어 서비스한다"
농업·어업 / 소프트웨어·컴퓨터프로그래밍·정보서비스 / 금융보험·임대(부동산 제외) / 전문과학기술(연구개발 제외)·사업지원·사회복지

② 포함 사항 · 세부내용

법 제25조: "조교작사" → 조교가 작사했다
조직과 직무 · 교육 · 작업장 안전·보건 관리 · 사고조사·대책 · 기타
별표3 세부내용: "총조교 안보사 위보" → 총 맞은 조교가 안보사에게 위로 보고한다
총칙 – 조직 – 교육 – 안전관리 – 보건관리 – 사고조사 – 위험성평가 – 보칙
  • 안전관리: 방호장치, 자율검사, 위험물질 보관, 작업허가, 보호구, 안전표지
  • 보건관리: 건강진단, 작업환경측정, 유해물질 취급, 질병자 근로금지, 보건표지

③ 절차 · 효력 · 벌칙

  • 산업안전보건위원회 심의·의결 (없으면 근로자대표 동의)
  • 단체협약·취업규칙에 반하면 그 부분은 단체협약·취업규칙을 따름 / 법에 없는 사항은 근로기준법 준용
  • 사업주·근로자 모두 준수 / 미작성 시 500만 원 이하 과태료
"위원회 없으면 대표님 · 단취가 이긴다 · 모르면 근기법 · 안 쓰면 오백"

④ 작성 시 유의사항

"상명한 현이(현의)가 정직(정즉)하다"
법정기준 상회 · 직무권한 명확 · 현장 실정 · 현장 의견 반영 · 정기 검토 · 법령 개정 시 즉시 개정
백 명이면 한 달 안에, 조교가 작사하고, 위원회 없으면 대표님, 안 쓰면 오백!

2-4+관련 법정계획: 개선계획 · 방지계획서

① 안전보건개선계획 (법 제49조~제50조)

재해가 많거나 위험한 사업장에 고용노동부장관이 명령해서 수립 (사고 후)

진단 받아 수립: 재·중·질·확
재해율 평균의 2배 이상 · 중대재해 · 질병자 · 화재·폭발·누출로 주변까지 피해 확산

시설 · 안전보건관리체제 · 안전보건교육 · 재해예방·작업환경 개선
  • 위원회 심의 (없으면 근로자대표 의견)
  • 명령일부터 60일 이내 지방고용노동관서 제출 → 15일 이내 심사 결과 통보
"육십에 내고 보름에 답"
